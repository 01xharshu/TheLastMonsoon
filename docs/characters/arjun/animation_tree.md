# Arjun locomotion AnimationTree — 2026-09-25

`player/arjun_motion_tree.gd` builds a Godot AnimationTree from the gameplay GLB's idle, swim idle, and swim forward clips, plus a runtime walk gait for the same rig. The imported walk held the hands near the hips with little visible stride, so the runtime gait adds alternating legs and opposite arm swing without changing the source GLB. The gait is based on the imported idle pose rather than the rig bind pose. Ground and water each use a one-dimensional blend; a final blend moves between them. The clips loop in memory, and the baked Root position track is removed so the CharacterBody3D controls travel and collision.

`player/arjun_visual.gd` advances the tree manually from actual horizontal speed and swimming state. Ground playback cadence increases with travel speed to reduce sliding. The visual rig lowers toward the lowest foot during walk phases; it does not move the collision body. The old forward model tilt is removed while the imported swim clip is active because that clip already pitches the body forward. Existing procedural poses still handle prone, cover, river actions, riding, weapon grip, and attacks; climbing uses tree poses with procedural hand targets. Those systems still need visual tuning and transition review. The tree is a locomotion foundation, not a completed animation set or an approval of Arjun's rejected temporary appearance.
