# Roadside shade avenues — 26 October 2026

Open approaches now receive additional shade trees instead of relying only on the existing scattered landscape slots. Period reference: Linnaeus Tripe's [1858 photograph of a banyan avenue at Seringham](https://www.clevelandart.org/art/1994.18), whose museum description records extensive shade planting along Salem roads. This supports the avenue treatment; it does not establish that every Indian road was continuously wooded or that fictional Suryagarh reproduces that particular location.

`world/suryagarh/roadside_trees.gd` adds deterministic paired planting stations about 14 metres apart, with trunks approximately 11 metres from surveyed road centres and modest verge variation. The original north–south road is split around the superseded upland section. Additional candidates follow Government House's approach, the east bridge/police connection, the cantonment approach and port service/approach roads. Junctions, surveyed plots/farms/factory reservations, river margins, steep terrain and existing solid objects reject candidates. Existing reserved consignment traffic clearance remains authoritative. The resulting count can change when another owner adds buildings or solid objects.

The addition reuses shared Peepal, mango and spreading broadleaf meshes; no new species identity is claimed for the generic spreading tree. Mature/younger sizes vary from 11–13.6 metres. Broad multi-root banyans remain with the existing terrain-suitability owner. Actual terrain rays establish roots, embedded 12 cm; existing woody-profile cylinders supply solid collision. Setup runs once after the existing landscape trees are repaired and varied. No save migration, per-frame planting scan or autonomous actor is added.

Rendering groups trees into Godot MultiMesh instances by species and 72-metre world tile. All batches reference the same three cached species mesh resources and their generated mesh LODs; tree placements are transforms, not separate copied tree meshes. Visual batches fade by 460 metres with a 40-metre margin. Trunk collision persists when foliage is beyond rendering range. Candidate count is bounded at 400, startup yields through the shared loading budget, and static objects need no simulation scheduler. Existing editable assets, landscape exports and all prior tree placements remain owned by their existing modules.

Reusable actual-world checks, with OS-temporary output/private userdata removed on exit:

```sh
python3 tools/world/run_roadside_trees.py
python3 tools/world/run_roadside_trees.py --native --review
```

The first checks actual New Journey terrain support, bounded counts, repeat-setup safety and cart-width clearance against every surveyed route. The native check also verifies visible root embedding, wood collision and count/LOD parity; samples paired hidden/visible new-tree frame times at the current Medium 3D budget in rural and village-approach views. Review captures last at most 90 seconds in the temporary folder and are deleted on exit. These bounded observations do not grant full-world FPS or final art approval.
