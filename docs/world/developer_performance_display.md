# Developer performance display

Enable **Settings → Developer → Advanced performance display** from the title or pause menu. The preference is saved locally and is off by default. The display stays at the right center of the screen while enabled, including during gameplay. It updates twice a second and shows FPS, wall-clock average and worst frame time for the latest interval, Godot process/physics time, render draw calls and objects, and Godot static memory. The process and physics values are engine monitor timings, not a total CPU utilisation percentage; CPU percentage is explicitly marked unavailable. Values may briefly reflect loading, menus or a paused game.

The focused `tools/world/validate_performance_display.gd` exercises the real settings toggle, live counter text, settings persistence and disable. Headless and native Metal checks passed on 2026-10-29; a native fixture image was inspected and discarded. These checks do not establish world performance. Existing native populated-world measurements in `runtime_optimisation.md` document substantial frame-time problems; this display diagnoses but does not fix them. For an immediate lower-cost setting, use Settings → Graphics → Medium or Low, then observe the counter after the world settles.
