# Look-at interaction glow

Updated 2026-10-26. The existing InteractionOverlay owns a FocusGlow child. It reads the same selected Interactable as the action prompt, keeping range, availability and selection consistent. It clears while the overlay is hidden, the map/menu is paused, inventory/weapon wheel is open, opening/story cinematics own control, or the target disappears. A physics visibility ray and normal shader depth testing prevent highlighting through solid walls.

The visual is a narrow warm gold diagonal shine sweeping across the selected object every 2.8 seconds, with a quiet interval and no constant surface tint. All highlighted submeshes share the object-space bounds so the sweep travels across the object coherently. It does not require environment bloom and does not add a light or duplicate meshes. Focus changes scan only the selected visual subtree. Existing source meshes/materials remain untouched; existing material overlays are retained as a next pass and restored exactly on release. Concurrent replacement of an overlay is respected during cleanup.

Interactables default to their own visible geometry. `highlight_root_path` can nominate a different authored Node3D for a proxy prompt. Existing attendant/staff/person/cart visual references are supported when the proxy has no geometry. Cart boarding points nominate the cart; unrelated child interactables and combat actors are excluded from a vehicle's highlight subtree. No whole-building parent fallback is used. New invisible proxy interactions should provide an explicit visual root when their object is not covered by an existing reference.

Reusable native verification: `python3 tools/world/run_tutorial_guard_check.py --native --checks validate_interaction_glow`. Add `--review` for temporary before/after pictures. The runner isolates project/userdata, rejects engine diagnostics and deletes pictures/logs on exit. Gates cover actual Player selection, source retention, no stacked passes, looking away, original overlay chain/restoration, wall occlusion, map/UI, deletion and authored proxy-root isolation. A native chest before/after view has been inspected; this is not a whole-world FPS or every-asset material approval.

Normal play: restart the main project, approach an available chest, pickup, door or cart, and face it until its interaction prompt appears. The selected visual receives a travelling gold shine. Turn away, move out of reach, use/collect it or open the map to clear the highlight.
