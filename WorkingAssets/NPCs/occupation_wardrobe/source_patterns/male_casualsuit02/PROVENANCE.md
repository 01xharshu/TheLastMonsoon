# MPFB male_casualsuit02 source pattern

Copied unchanged from the installed MPFB asset collection for reproducible occupation garment authoring. The `.mhclo` and `.mhmat` headers explicitly identify the September 2020 CC0 release and the original holders: Data Collection AB, Joel Palmius and Jonas Hauquier. Those headers are preserved. See https://creativecommons.org/publicdomain/zero/1.0/ for CC0 terms.

The upper and lower pattern components are fitted over the retained complete project MPFB body. These files are build inputs, not approved runtime clothing. The original textures are included because the source material references them; runtime cotton styling is separately authored.
